# The Go goldens, and the programs that produce them

Two of `crates/mw-web`'s tests assert against output produced by **running** Go rather than
against a reading of it, which is how M4-2 pinned the enrich formulae and the only way a
claim like "this reproduces `html/template`" can be checked instead of believed:

| Golden | Asserted by | Produced by |
|---|---|---|
| `crates/mw-web/tests/golden/go-escapes.tsv` | `crates/mw-web/tests/escaping.rs` | `escapes/` |
| `crates/mw-web/tests/golden/go-content-types.tsv` | `crates/mw-web/tests/mime.rs` | `mime/` |

**They live here rather than under `scratch/` because `scratch/` is in `.gitignore`.** M4-3's
code review found both goldens generated by programs nobody who checked out the branch could
run — one of them with an absolute path containing the runtime's working directory — which is
the opposite of the "checked rather than believed" argument the tests rest on.

## Regenerating

From the repository root, with Go on `PATH`:

```sh
cargo xtask go-golden
```

That is the supported path and it is what keeps the paths right: both programs resolve
`crates/mw-web/assets` relative to the working directory, and `xtask` runs them from the
repository root. Running `go run .` by hand works from the root too.

`escapes/` renders a one-action `html/template` in four contexts — HTML text, a quoted
attribute, `<title>` and a JavaScript string inside `<script type="application/json">` —
over every ASCII codepoint and a list of adversarial strings, plus `jsValEscaper` over a set
of floats and integers. Input and output are hex-encoded so the table survives a round trip
through any editor; a fourth column carries the Go-quoted forms for a human.

`mime/` runs `http.FileServer(http.FS(os.DirFS("crates/mw-web/assets")))` over the tree this
crate embeds and records the status and `Content-Type` of every file, plus the four directory
paths **DEV-3** turns into 404s.

**A regeneration is a reviewable diff, not a refresh.** If either table changes, something
about Go's behaviour or about the asset tree changed, and the question is which.
