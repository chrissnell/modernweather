# `contract/` — the frozen legacy REST surface

The executable half of W1. The prose is [`docs/legacy-api-contract.md`](../docs/legacy-api-contract.md).

| Path | What it is |
|---|---|
| `legacy-v1.json` | the machine-readable contract: endpoint inventory, query parameters, status codes, every response type's fields with their Go types and `omitempty` flags, the Swift decode targets, the 109-row client crosswalk, the 2-row hazard table, 20 quirks, and the fixture index. Generated by `tools/genschema.py` from the Go and Swift sources — nothing in it is hand-transcribed except the endpoint and quirk prose in `tools/endpoints.py`. |
| `fixtures/*.json` | 70 captured responses, one file each, carrying the request that produced it, the response, its **class**, its provenance, its own assertion set and — for two of them — a recorded **deviation**. |
| `conformance/` | a standalone Rust crate that replays the fixtures against any HTTP base URL. |
| `tools/` | the capture harness and the throwaway rig it captured from. |

## Running the conformance suite

```sh
cd contract/conformance

# against the Go daemon — this is the fixture-validity check
cargo run --release -- --base-url http://127.0.0.1:8080

# against the Rust daemon — this is the rewrite check. DEV-10 is a response this target
# differs on by design; see "Three classes and one deviation" below.
cargo run --release -- --base-url http://127.0.0.1:8080 --deviation DEV-10

# as a test, for CI
CONFORMANCE_BASE_URL=http://127.0.0.1:8080 cargo test --release
```

Exit code is 0 only when every fixture passes. **That is not the same as the gate being green** —
the gate applies a policy per class and lives in `xtask/src/conformance.rs`; this runner reports.
`cargo test` with no `CONFORMANCE_BASE_URL` skips itself, so a plain `cargo test` in a fresh
checkout is green.

`--fixtures <DIR>` (or `CONFORMANCE_FIXTURES`) overrides the fixture directory; the default is
`contract/fixtures` relative to the crate.

## Three classes and one deviation

Every fixture carries a `class` — work item **N-18**, `docs/reconciliation.md` §6.4. The runner
**reports** it, per fixture and per class, and replays all 70 regardless: what a class means for a
gate is the gate's policy, and a classification that narrowed the replay would be exactly the silent
filter the gate's `attempted == 70` assertion exists to prevent.

| Class | Count | What a diff means |
|---|---|---|
| `frozen` | 42 | a **contract break**. The five endpoints the iOS client calls, and that client is deployed independently of the server |
| `coupled` | 19 | a **lockstep change**. The website's endpoints may change, but only in the same PR as the server and the embedded JavaScript — they ship as one binary |
| `retired` | 9 | nothing. `/alerts`, `/api/remote-stations` and `format=msgpack` are not carried forward (**D-69**); the fixtures are **kept** so the replay still attempts all 70 |

A fixture may also carry a `deviation`: a second recorded response, with an id, for a target that is
known to differ on purpose. `--deviation <ID>` compares against that one instead. There is one,
**DEV-10** on the two `/stationinfo` fixtures whose Go response omits `about_text` or
`weather_device` — `docs/reconciliation.md` **O-5**, answered by the owner as option (b), because
the iOS client declares both properties non-optional and an absent key fails the decode of the whole
object. One fixture holds both halves, which is what lets the Go-target replay keep asserting what
shipped while the Rust-target replay asserts the fix.

An id no fixture declares is a **refusal**, so a typo cannot silently make a target assert the wrong
half.

## What "conformant" means

Not byte equality — the values change every two seconds. It means the properties a client can break
on: status code, the recorded headers, the exact JSON key set at every level in both directions,
every value's JSON type, numeric formatting against Go's shortest-round-trip rule, key order where
the encoder is deterministic, trailing-newline presence, byte-exact plain-text error bodies, and
required substrings in HTML and script bodies. `docs/legacy-api-contract.md` §8 has the full list
and the reasoning.

## Prove the suite still bites

A green suite is meaningless if the runner asserts nothing. `tools/rig/mangle_proxy.py` forwards to
a real server while introducing four realistic regressions:

```sh
python3 contract/tools/rig/mangle_proxy.py &        # listens on 127.0.0.1:18081
cd contract/conformance
cargo run --release -- --base-url http://127.0.0.1:18081   # must FAIL
```

26 of the 70 fixtures must fail, naming the missing key, the `0.0`, the retyped `ts` and the lost
newline. CI should run this alongside the positive suite.

**26 is the count against the Go daemon, which passes all 70 directly.** Against a target that does
not serve every endpoint it is the wrong shape of assertion, not just the wrong number:
`xtask/src/conformance.rs` therefore measures what the proxy **broke** — `direct.passed -
control.passed` — which is independent of how many endpoints the target does not serve. Against the
Rust binary that is 23 of the 48 it serves, with a declared floor of 20.

## Adding a fixture

Add one `spec(...)` line to `tools/capture.py`, **with its `cls=`**, and re-run it against a live
server. The fixture file is self-describing, so the runner needs no other change — but
`xtask/src/conformance.rs` asserts the per-class counts and the fixture total against the tree, so a
new fixture is a deliberate change to the contract in two places rather than one.

## Do not hand-edit

`legacy-v1.json` is generated; edit `tools/endpoints.py` or the Go/Swift sources and re-run
`tools/genschema.py`. Fixture files are captured; re-run `tools/capture.py`. A hand-edited fixture is
a fixture that no longer describes a real server.

**Two fields are the exception, and both survive a re-capture by being declared on the `spec(...)`
line**: `class` and `pending`. A `deviation` block does **not** — it records a response the Go server
does not produce, so there is nothing to capture, and a re-capture drops it. The gate then fails
naming the deviation it could not find, which is the right failure: a deviation whose fixture has
been recaptured needs its new half re-derived from the new recording.
